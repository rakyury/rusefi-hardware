## Смета

В `26bb092` согласован собственный вариант SOT-23 для D5604: изменены только две линии шелкографии и имя посадочного места. Все площадки, медь, маска, паста, pin-1 и электрические цепи сохранены. Native silk-over-mask 2 → 0, library mismatch 0. Схема, BOM и PCB используют одно имя. Независимая root-проверка подтвердила 22 контрольные суммы и ограниченный parsed delta; см. `docs/reviews/2026-10-28-gdi6-d5604/`.

В `403f73f` разведены WBO1_CAN_RX/TX между U5602 и U5605: 9 дорожек и 2 переходных отверстия. После полной перезаливки земли на новых UUID нет DRC-замечаний; оба конца цепей соединены по независимой native KiCad проверке. Полный connectivity count 2099 → 2097. Сохранены все 2654 исходных объекта меди и все footprints/pads; изменена только заливка In1 GND вокруг новых vias. Root повторно сверил 22 хеша и неизменность схемы/BOM/сумм; см. `docs/reviews/2026-10-28-gdi6-wbo-can/`. Пределы правил не ослаблялись, исключения не добавлялись.
