# Offline validation repair — 25 October 2026

Reported symptom: `Power8GDI offline validation / host-contracts
(windows-latest)` failed. The same static assertion failed on Ubuntu and in
the separate pinout job at PR #4 head `94296e1e007834fb5ba38386c48b06827543a98f`.
This was not a compiler or Qt startup failure.

## Interface contract

The test compared the obsolete interface-only starter
`hardware/Power8GDI_RevA.kicad_sch` with the active pinout CSV. The starter had
`DIN5..DIN8`; the then-current CSV had the third/fourth motor bridge terminals.
Neither that stale comparison nor an eight-channel target represents the
user-approved six-cylinder redesign.

The active contract is now checked against the actual exported KiCad root
netlist `hardware/design/core.net`: all 136 connector positions, explicit
unused positions, the six DI pairs, two HPFP pairs and removed physical
assemblies. The old interface drawing remains historical. The electrical CI
regenerates the root export from the real schematic, so a stale committed
netlist cannot substitute for checking the circuit.

## Source provenance

The electrical job independently failed in
`interfaces_aux/test_aux.py::test_primary_source_provenance_and_upstream_blobs`.
Three text hashes had been captured from a Windows CRLF checkout; Git stores
the same reviewed blobs with LF. The first mismatch was
`lambda-x2/readme.md`: CRLF `752a838f…`, LF/Git blob `4ad11216…`.

The manifest now explicitly records `lf_sha256` and policy
`CRLF_TO_LF_ONLY`. Verification also reconstructs and checks the original Git
blob ID, without needing a Git executable or repository history in a source
archive. Only CRLF pairs are normalized: spaces, encoding, lone CR and final
newline changes remain significant. Downloaded manufacturer PDF hashes are
unchanged raw-byte hashes. No upstream design files are rewritten.

Regression tests exercise both LF and CRLF variants of every reviewed text
source and reject content, whitespace and lone-CR mutations. The explicit
provenance refresh command refuses local source changes that disagree with
the pinned Git blob. CI never refreshes expected hashes automatically.
