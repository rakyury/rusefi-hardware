## Что уточнилось после подготовки PDF

- Пользователь подтвердил **физическую переделку платы на 6 DI + 6 PI**, два
  ТНВД, два моторных моста DBW/EWG и одну лямбду. Старый вариант Huge/GDI8
  является исходной точкой, а не активным количеством каналов.
- Найден существующий PyQt6 конфигуратор и C++/Python 4D codec, host-политики
  двух ТНВД и PT2001. План не требует создавать их заново: сначала проверяется
  и адаптируется существующая реализация. Архитектурный выбор GUI из исходного
  плана теперь имеет конкретную существующую базу в `Power8GDI/configurator/`.
- Пользователь потребовал инструменты по скриншотам EMU PRO, **VM и CAN из
  Racing Dash**. Это дополнительное требование к собственному клиенту;
  исключение Lua остаётся в силе.
- BOM и стоимость 1/10 PCBA составляются **после доработки схемы**, из её
  конкретного нетлиста. Архивный восьмицилиндровый BOM не используется как
  окончательный шестициллиндровый.

При расхождении этих уточнений с ранними фразами PDF действует активное ТЗ.
Числа на скриншотах не являются рекомендованными настройками двигателя.

|---|---|
| rusEFI | `5a42c8b3df0ab1540327c5648cb81ef1b58ab2a9` |
| FOME master | `9f45bdeeb59080a09f3fd7ca8568c7ef73372fb6` |
| FOME stable | `343fb818014f082a14dc7dd25e69c29cfbd5bafb` |
| Исторический gurovefi | `cb7cb8528911e549c254a0339ebc06aac25ee73e` |

Внутри отчётов приведены ссылки на конкретные файлы и строки. Исторический
gurovefi не объявляется текущим исходным кодом epicEFI. Донорская реализация
не считается пригодной без адаптации и проверки полного пути до исполнительного
события. Результаты прежнего реверса EMU PRO имеют разные уровни доказательности.

Приватные материалы EMU PRO перечислены в [реестре источников](evidence_manifest.md).
Они не публикуются вместе с этой документацией. Машинные ссылки в Markdown
заменены на записи реестра; PDF сохранены побайтово как первоначальные документы.
[Манифест](manifest.json) содержит SHA256 исходных и включённых файлов.

## Сопоставление с уже существующим кодом

| Работа из плана | Существующая база | Следующий необходимый шаг |
|---|---|---|
| ECU-09/11, DI+PI и два ТНВД | `firmware/dual_hpfp/`, `firmware/dual_gdi/` | Индивидуальные конечные DI-массы по рампам, профиль 6, реальные таймеры/драйверы |
| Таблицы и обмен | `firmware/include/map4d*`, `configurator/.../map4d_binary.py` | Единая схема, ограничения ECU, измерения на MCU |
| ECU-28/31/32, клиент | `configurator/` | Явный новый профиль, миграция, удобные инструменты, совместимый протокол |
| ECU-25/29/33-35, VM/CAN | Собственный Racing Dash и открытые компоненты rusEFI tuner | Зафиксированный перенос с проверками совместимости и ограничений |
| ECU-03/27, аппаратная интеграция | `hardware/design/` | Новая шестициллиндровая схема, BOM, PCB и проверки именно новой версии |

Это сопоставление показывает места продолжения работ. Оно не приравнивает
наличие файлов к выполнению приёмки ECU-01..38.
