# WBO placement reference for board integration

`layout_reference.json` records every retained source footprint's actual XY,
orientation, layer, copper-pad bounds, original reference and both target references.
It is generated with pcbnew by `layout_reference.py` from the pinned0.6 reference
PCB; no copper has been copied and no target PCB is generated by this script.

The original module is **two-sided**. Its retained component-pad envelope is
x78.2647..101.9232, y81.5..94.55mm (23.6585x13.05mm). Analog components occupy
x78.98..99.505, y81.5..94.395mm (20.525x12.895mm), shared across both sides.
The analog ICs U600 MCP6004 and U601 AD8628 are on B.Cu; F042 and REF3033 are on
F.Cu. Keep that layer relationship when using the stored reference transform.

The proposed initial transform scales position offsets by1.65 and adds2mm edge
margin, reserving roughly43.04x25.53mm for the original core per channel. This is
only a starting point for the enlarged0603 passives: it is not a proved legal
placement. Reserve another20x25mm nearby for changed heater DPAK, reverse diode,
bulk/TVS and added inhibit gates. Two channels therefore need materially more
space than the old compact module, and still need physical placement/DRC review.

Maintain U600 with its feedback RC groups R602/R603/R604/C603 and R610/R611/R612/
C605/R607, and U601 with R621/R624/C608. Keep supply decoupling at the actual
op-amp/reference/MCU power pins rather than applying the global scaling blindly.
Do not place heater/motor/ignition switching copper underneath the sensitive
amplifier and sensor paths; heater return must reach power ground without sharing
a narrow analog-ground connection. Keep sensor VM separate from GND per the
electrical source topology.

Important changes prevent blind source-layout reuse:0402→0603 passives; Q600
SOT223→DPAK with a different pad count; CAN transceiver footprint adaptation;
external SWD header footprint; extra heater safety gates, feed diode, TVS andbulk.
Before any copper reuse, compare actual pad numbers and corrected source/target
net partitions. The WBO analog-net-collision fix286bdf1 must already be integrated.
The stored original Q600 location must not be accepted as a DPAK placement.

Source schematic and PCB retain upstream attribution and the existing unresolved
hardware redistribution/license gate; copying placement does not resolve it.
