# Источники прежнего реверса EMU PRO

Это инвентаризация материалов, использованных в плане. Исходные бинарные образы, калибровки и полные материалы частного исследования в публичный hardware-репозиторий не копируются.

Часть исследования опубликована в отдельном закрытом [репозитории EMU PRO](https://github.com/rakyury/emu-pro-firmware-research), проверенный HEAD `55a39f57ef5c7106a06dbd53b3527445916df4cf`. Наличие там поздних файлов `engine_logic/` не подтверждено: README этого каталога через API не найден. Поэтому ссылки плана ведут на этот реестр, а не на несуществующие GitHub-страницы.

В исходных PDF сохранены локальные ссылки первоначальной выдачи. Для совместной работы используйте Markdown-план и идентификаторы E0-E10 ниже. Точные версии фиксируются SHA256; содержимое источников доступно владельцу исходного исследования.

Классы доказательств: A - непосредственно наблюдаемые адреса/ветви/поля; B - реконструкция; C - не восстановлено; UI - метаданные или скриншот. Наличие поля не доказывает алгоритм.
