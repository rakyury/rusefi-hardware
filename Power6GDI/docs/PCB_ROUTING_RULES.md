# Routing rules and unresolved fabrication assumptions

Regulated `+3V3*` and `+5V*` rails use `LogicSupply`: 0.2 mm clearance, 0.4 mm preferred trace width. Actual neck width and trunk current capacity are independent requirements. The former generic battery rule imposed 0.3 mm on these rails, although the actual STM32/QFN land patterns have adjacent 0.5 mm-pitch, 0.25 mm-wide pads (0.25 mm copper gap). The generated 0.25 mm MCU fanout has a measured 0.225 mm pad-to-trace gap. Assigning the ordinary 0.2 mm low-voltage clearance resolves this classification error without changing the package.

Battery nets retain 0.3 mm clearance; GDI boost nets retain 0.6 mm; ignition primary collector nets retain the explicit provisional 2.5 mm engineering target. No DRC exclusions or severity suppressions are added. High-voltage pulse/connector qualification remains open as recorded in `PCB_IGNITION_INSULATION.md`.

The 0.2 mm global track minimum remains unchanged. The capped width-error sample consists of 0.15 mm PT2001 VSENSEP/N tracks. These are measurement inputs, not actuator-current copper; the selected devices are MC33PT2001AE, with pin roles documented in the [NXP PT2001 short datasheet](https://www.nxp.com/docs/en/data-sheet/MC33PT2001_SDS.pdf), Table 2. A narrower dedicated sense rule needs a confirmed board manufacturing process and complete physical review. For example, the [JLCPCB capability table](https://jlcpcb.com/capabilities/Capabilities?type=1) lists 0.15/0.15 mm for multilayer 2 oz, while its [copper-weight guide](https://jlcpcb.com/help/article/jlcpcb-copper-weight) lists 0.16 mm for 2 oz. This conflict and existing nominal 0.1495 mm donor spacings prevent using either table as blanket approval. No fabricator has been selected or contacted.

The common voltage policy derives 60 PT2001 switching nets from actual pin connectivity, including floating bootstrap/gate/source and boost-recovery paths. All receive the existing provisional 0.6 mm target. PTA/PTB_+Batt_filtered are explicit 0.3 mm battery aliases through their input inductors. LP5_SW and LP5_BOOT also use 0.3 mm: actual U5200 pins 1..5 switch the input supply, and pin 6 floats above SW. See [TI LM76003-Q1 datasheet](https://www.ti.com/lit/ds/symlink/lm76003-q1.pdf), Rev B section 6.1, for the SW relative-to-VIN and BOOT relative-to-SW limits. This is not a complete voltage-domain audit: motor protected supply/charge-pump paths still require review; a default 0.2 mm classification does not certify them as regulated logic.

The logic routing export now keeps every existing copper item as a protected physical obstacle, replacing the obsolete whole-GDI B.Cu exclusion. It exposes only a reviewed digital allowlist, with separate protected battery/boost/ignition classes. In1 remains the ground layer. Imported sessions must match both board and rule hashes; the importer adds only allowed copper and verifies every original segment/via remains. Export support is implemented; no generic-router completion or accepted session is claimed by this rules update.
